# 🌿 Urban Harvest Dashboard

A modern and responsive admin dashboard built with **React JS**, **Redux Toolkit**, and **Material UI** for a fictional food delivery/admin platform called **Urban Harvest**.

---

# ✨ Features

## 🔐 Authentication
- Responsive Login Page
- Email & Password Fields
- Remember Me Option
- Modern UI Design

## 📊 Dashboard
- Responsive Sidebar Navigation
- Modern Header
- Statistics Cards
- Recent Orders Table
- User Profile Section
- Mobile Responsive Layout
- Hamburger Menu for Mobile

## 🛍 Product Management
- Product Cards
- Search & Filter Functionality
- Product Status Tags
- Add Product Button
- Responsive Grid Layout

---

# 🛠 Tech Stack

- React JS
- Redux Toolkit
- React Router DOM
- Material UI (MUI)
- MUI Icons

# 🚀 Getting Started

## 1️⃣ Clone Repository

```bash
git clone <your-repository-url>
```

---

## 2️⃣ Navigate to Project

```bash
cd urban-harvest-dashboard
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

Or install manually:

```bash
npm install @mui/material @emotion/react @emotion/styled
npm install @mui/icons-material
npm install react-router-dom
npm install @reduxjs/toolkit react-redux
```

---

# ▶️ Run Project

```bash
npm start
```

The app will run on:

```bash
http://localhost:3000
```
